# FinRise PDF Toolbox - downloads

FinRise PDF Toolbox is a Windows PDF utility (merge, split, compress, rotate, crop,
protect, OCR, and PDF to Word / Excel / PowerPoint). All processing happens on your
own computer; documents are never uploaded.

**The app is currently available by invitation only.** The installer below needs a
licence key, which invited users receive by email.

* Latest installer: see [Releases](../../releases/latest)
* Installed copies update themselves from this page.

## Open-source components

The app bundles MuPDF (AGPL-3.0) and Tesseract OCR with its libraries (Apache-2.0,
LGPL, GPL and permissive licences). Their complete source code is attached to every
release:

* `mupdf-1.27.0-source.tar.gz` - MuPDF source
* `finrise-pdf-toolbox-ocr-sources.zip` - source of the OCR component and its libraries,
  with the build recipes and patches used

The full list of components and licences is in `THIRD-PARTY-NOTICES.md` in the app's
installation folder.
